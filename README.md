# Self-Balancing-Propeller-Arm
A single-axis self-balancing system designed and built from scratch using a Raspberry Pi Pico 2 W, MPU-6050 IMU, brushless motor/ESC and a custom 3D-printed structure. The system uses IMU sensor fusion and closed-loop PID control to regulate the arm to an 8° setpoint. It converges to within approximately ±1° of the target within 5–10 seconds.
